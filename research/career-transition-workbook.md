# Career transition workbook · February 2027 target

**Purpose:** Prepare accurate resume and profile updates for a February 2027 company move. This is a blank planning checklist, not a resume, profile submission, or job application.

**Privacy:** Keep completed personal values, the actual resume, contact details, compensation, work authorization, references, and private company/client information in a secure personal location. Do not commit filled answers, passwords, OTPs, government IDs, or account recovery details to this repo. Share only the fields needed for a specific review. Redact confidential client, product, customer, and employer data before using examples.

## 5. Resume package and review gates

- [ ] Confirm source resume and date of last update.
- [ ] Reconcile chronology and role titles against work records.
- [ ] Build a master resume from verified facts.
- [ ] Select role families and create only relevant tailored versions.
- [ ] Check every technical claim, metric, ownership verb, link, and date.
- [ ] Review ATS readability, spelling, length, and consistent formatting.
- [ ] Approve final resume content before uploading anywhere.
- [ ] Store final versions in a private location; do not publish the file in this repository.
